## 🌟 Key Features
* **Multi-Service Integration:** Seamlessly switch between Spa, Hotel, and Food services.
* **Dynamic Cart System:** Real-time price calculation with LocalStorage persistence.
* **Social Impact Tracking:** Integrated NGO section where every booking contributes to a cause.
* **Modern UI/UX:** Built with Tailwind CSS for a fully responsive, mobile-first experience.
* **Direct Inquiry:** Integrated WhatsApp and Email communication channels.

## 🛠️ Technology Stack
* **Frontend:** HTML5, Tailwind CSS
* **Logic:** Vanilla JavaScript (ES6+)
* **Icons:** FontAwesome
* **Payments:** Razorpay Integration Ready
